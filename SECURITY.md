# Security policy

## Reporting a vulnerability

If you find a security issue in any TransactionTree API documented here — or in the docs themselves (e.g., a real credential or internal-only endpoint accidentally published) — please report it privately:

1. **Preferred**: use [GitHub's private vulnerability reporting](https://github.com/TransactionTree/api-transactiontree-com/security/advisories/new) on this repo.
2. **Alternative**: email `security@transactiontree.com`.

Do **not** open a public GitHub issue for security matters.

## What to include

- Affected endpoint, request, or commit
- Reproduction steps if applicable
- Your assessment of severity and impact

## Response expectations

- Acknowledgement within 2 business days
- Initial triage within 5 business days
- Coordinated disclosure timeline agreed once severity is confirmed

## Scope

This policy covers:
- Documentation hosted at `https://api.transactiontree.com`
- The Postman collection in this repo
- Any TransactionTree-operated API surface documented here

The published documentation portal at `api.transactiontree.com` is rendered by Postman from this repo. Vulnerabilities in Postman itself (the hosting platform) should be reported to Postman directly via their [security program](https://www.postman.com/security/).
